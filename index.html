Come creare Card Game Multiplayer su GitHub Pages

GitHub Pages ospita solo file statici (HTML, CSS, JS) e **non possiede un backend/server Node.js**. Spieghiamo come superare questo limite mantenendo la privacy delle carte in mano tramite **PeerJS (WebRTC)**.

1. Modello Host-Authority (Peer Master)

L'utente che "Crea la Stanza" diventa l'**Host**. L'Host conserva nel suo browser lo **stato segreto globale del mazzo** (es. l'ordine esatto delle carte non ancora pescate). Nessun altro client conosce il mazzo completo.

2. Data Privacy (Mano Privata)

Quando un giocatore pesca, l'Host invia i dati del seme/valore **esclusivamente al canale P2P privato** di quel giocatore. Agli altri avversari invia solo una notifica generica: COUNT_UPDATE.

3. PeerJS & WebRTC Signal Server Free

PeerJS offre un server di segnalazione cloud **gratuito**. Serve solo per far scambiare gli IP (handshake). Una volta stabilito il canale WebRTC, i messaggi viaggiano **direttamente da browser a browser** a latenza bassissima!

4. Costo Zero Hosting

Poiché tutto il codice gira nel client dell'utente e il networking usa WebRTC P2P, l'hosting ha costo zero. Può supportare centinaia di partite contemporanee senza alcun server da pagare.

Flusso Messaggi P2P per Mantenere il Segreto

// 1. Giocatore A chiede di pescare una carta
Player_A ──> [MSG: DRAW_REQUEST] ──> Host

// 2. L'Host estrae la carta dal mazzo globale ed invia il VALORE solo a Player A
Host ──> [MSG: DRAW_RESPONSE {card: 'Asso di Picche'}] ──> Player_A (Canale Privato)

// 3. L'Host notifica a TUTTI GLI ALTRI solo il conteggio aggiornato
Host ──> [MSG: PLAYER_HAND_UPDATE {peerId: 'Player_A', count: 4}] ──> Broadcast a tutti

Come pubblicare questo progetto su GitHub Pages

  1. Crea un nuovo repository su GitHub (es. card-game-p2p).
  2. Copia questo singolo file HTML e salvalo come index.html nella root del repository.
  3. Fai il push del file sul tuo repository: git add . && git commit -m "Initial commit" && git push.
  4. Vai nelle impostazioni del repository GitHub: Settings > Pages.
  5. Sotto Build and deployment, seleziona il branch main (o master) e la cartella /(root). Premi Save.
  6. Dopo pochi secondi il tuo gioco sarà raggiungibile online all'indirizzo https://tuo-nome.github.io/card-game-p2p/!
